# Agent working files

These are internal development records, not documentation. They exist so an
agent — Codex or Claude Code — can resume work without re-deriving state, and
because several of them are the evidence trail behind release claims.

| File | What it is |
| --- | --- |
| [development.md](development.md) | The tracker and handoff. Current status, batch scope, durable decisions, and the exact next action. Read this first when resuming. |
| [verification.md](verification.md) | Chronological test-run evidence. Historical; consult it for a specific unresolved issue rather than as a starting point. |
| [performance.md](performance.md) | Static performance review and the profiling that has not been done. |
| [research.md](research.md) | Platform API inspection notes from the September 11 SDK review. |

**Looking for documentation?** User-facing docs are in [`docs/`](../docs/) and
usage lives in the [README](../README.md). Nothing in this folder is intended
as guidance for consumers of the package.

The workflow rules an agent should follow are in [AGENTS.md](../AGENTS.md).
